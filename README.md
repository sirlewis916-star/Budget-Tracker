
# SpendWise 💰
This week, SpendWise was enhanced with interactive features using JavaScript. The application now allows users to add expenses, view a real-time dashboard, and get budget status alerts.

## Improvements Made
- Added expense tracking with description, amount, and category
- Implemented real-time dashboard updates
- Added budget status alerts (over budget, 80% used, within budget)
- Enabled expense deletion

## Conditionals
Conditionals (`if/else` statements) are used to:
- Check if expenses exceed income → show "Over budget" alert
- Check if 80% of income is used → show warning
- Validate user input (description and amount required)
